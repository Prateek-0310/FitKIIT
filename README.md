# FitKIIT

A comprehensive Flutter application designed for fitness tracking and community engagement. FitKIIT enables users to track their fitness activities, view announcements, manage their profile, and connect with other community members.

## Features

- **Home Pass Screen**: Access your dashboard and quick action items
- **Fitness Tracking**: Monitor and log your fitness activities
- **Announcements**: Stay updated with the latest announcements and community news
- **User Registration**: Easy signup process with profile creation
- **Profile Management**: Customize and manage your personal profile
- **Community Engagement**: Connect with other fitness enthusiasts

## Prerequisites

Before you begin, ensure you have the following installed:

- **Flutter SDK**: Version 3.0 or higher ([Install Flutter](https://flutter.dev/docs/get-started/install))
- **Dart SDK**: Included with Flutter
- **Android Studio** or **Xcode** (for iOS development)
- **Git**: For version control

## Installation

### 1. Clone the Repository
```bash
git clone <repository-url>
cd FitKIIT
```

### 2. Install Dependencies
```bash
flutter pub get
```

### 3. Run the Application

For Android:
```bash
flutter run -d android
```

For iOS:
```bash
flutter run -d ios
```

For Web:
```bash
flutter run -d chrome
```

## Usage

1. **Launch the App**: Run the application using the commands above
2. **Register**: Create a new account with your details
3. **Explore**: Navigate through the home, announcements, and profile sections
4. **Manage Profile**: Update your profile information and preferences
